# Contributing

## Tests and fixtures

Tests, fixtures, docs, screenshots, and commits must never copy real inbound mail. Do not use a real person's name, email address, or phone number. Use a fictional name and an `example.com` address. Public site addresses that are already part of the product, such as `hello@celticcoo.ca` and `bookings@celticcoo.ca`, may appear where the product uses them.
